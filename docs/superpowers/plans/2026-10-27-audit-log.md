# Audit Log Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ghi mỗi HTTP request thành một bản ghi audit (status, error_message, request/response body và thay đổi entity đã mã hóa) qua Channel + BackgroundService, lưu ở schema `audit`, kèm API danh sách và chi tiết.

**Architecture:** Middleware (WebAPI) bắt request/response, dựng entity `AuditLog` đã mã hóa rồi `TryWrite` vào `Channel`; `BackgroundService` (Infrastructure) đọc batch và ghi qua `IAuditLogRepository` + `IUnitOfWork` trong scope riêng. `ApplicationDbContext.SaveChangesAsync` đẩy thay đổi entity vào `IAuditContext` (scoped), middleware gộp vào bản ghi của request. API đọc là MediatR query trả `Result<T>`.

**Tech Stack:** .NET 10, EF Core 10 + Npgsql, MediatR 14, System.Security.Cryptography.AesGcm, System.Threading.Channels, xunit (project test mới).

**Spec:** `docs/superpowers/specs/2026-10-27-audit-log-design.md`

## Global Constraints

- Lệnh chạy từ thư mục gốc repo `Z:\CongThien\Temp\BaseCleanArchitecture`.
- Bảng `audit.AuditLogs` (schema `audit`), PostgreSQL. Cột: `Id` (Guid v7), `AuditType` (chuỗi `Activity`/`Exception`), `StatusCode` (int), `ErrorMessage` (plaintext, nullable), `HttpMethod`, `Path`, `UserId` (Guid?), `Username` (string?), `DurationMs`, `RequestBody`/`ResponseBody`/`Changes` (mã hóa, nullable), `IsRequestTruncated`/`IsResponseTruncated` (bool), `CreatedAt` (DateTimeOffset UTC).
- Không lưu header. Lưu mọi request, không có danh sách loại trừ.
- Mã hóa: AES-256-GCM, nonce ngẫu nhiên mỗi lần, định dạng `v1:` + base64(nonce12 | tag16 | ciphertext). Khóa 32 byte base64 ở `AuditEncryption:Key`; thiếu/sai thì app **không khởi động**.
- Body: trần mặc định 1 MB (`Audit:MaxBodyBytes`), cắt thì bật cờ truncated; body không phải văn bản (không phải JSON, XML, `text/*`, `application/x-www-form-urlencoded`) lưu chuỗi `[binary content, N bytes]`.
- `error_message`: Exception = `"{ExceptionType}: {Message}"`; status >= 400 không có exception = lấy `message`, rồi `detail`, rồi `title` từ response JSON, không có thì null. Không lưu stack trace.
- Channel bounded, mặc định 10.000, đầy thì bỏ bản ghi mới và log cảnh báo, không chặn request. Lỗi audit không bao giờ làm lỗi request.
- `status` filter là mã HTTP chính xác. `pageSize` mặc định 20, tối đa 100. Sắp xếp `CreatedAt` giảm dần. List không trả body/changes; detail trả đủ (vẫn mã hóa).
- API route `api/audit-logs`, chưa yêu cầu đăng nhập.
- Giữ chiều phụ thuộc: WebAPI → Application → Domain; Infrastructure/Persistence cài đặt abstraction của Application/Domain. Infrastructure **không** tham chiếu Persistence.
- Commit kèm dòng cuối `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
